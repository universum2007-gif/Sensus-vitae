# Sensus Vitae — Learning and Knowledge-Check Policy

## 1. Educational goal

Sensus Vitae should support active learning, not only passive reading.

Where appropriate, educational material should help the learner move through:

Understand → Connect → Recall → Apply → Check

Learning features should improve understanding and retention without turning the site into unnecessary gamification.

---

## 2. When to use learning checks

For suitable:

- educational articles;
- chapter summaries;
- course notes;
- concept explanations;
- scientific learning modules;

consider adding a short learning check when it meaningfully improves learning.

Do not add a quiz merely because the technical component exists.

The learning check should correspond to the actual learning objectives of the page.

A typical learning check contains approximately 3–7 questions depending on the complexity and length of the material.

---

## 3. Question formats

Suitable formats include:

- multiple choice;
- true / false;
- matching;
- short conceptual questions;
- applied scenarios;
- interpretation questions.

Prefer questions that test:

- conceptual understanding;
- mechanisms;
- causal relationships;
- important distinctions;
- application;
- interpretation;
- common misconceptions.

Avoid questions that merely test recognition of an isolated word or trivial detail unless that detail is genuinely important.

---

## 4. Scientific accuracy

Quiz questions and answer keys are scientific content.

They must follow the same scientific standards as articles.

Do not create questions that reinforce an oversimplification merely because it makes the quiz easier.

If more than one answer can reasonably be considered correct, rewrite the question.

Distinguish carefully between:

- established evidence;
- theoretical interpretation;
- historical claims;
- educational simplifications.

---

## 5. Educational feedback

Prefer educational feedback over score-only feedback.

Where practical, after an answer show:

- whether the answer is correct;
- the correct answer;
- a short explanation;
- the relevant misconception if useful;
- a link or reference back to the relevant section of the article when helpful.

The purpose is to teach, not merely to grade.

---

## 6. Privacy

By default, learning checks should work locally in the browser.

Do not require:

- an account;
- registration;
- a name;
- an email address.

Do not transmit or store:

- individual answers;
- scores;
- learning profiles;
- behavioral learning data;

unless the owner explicitly approves such functionality after a privacy review.

Do not add analytics or tracking to learning checks by default.

---

## 7. Accessibility

Learning checks must be usable with:

- keyboard navigation;
- screen readers;
- mobile devices;
- touch interaction.

Use proper semantic controls and labels.

Maintain visible focus states.

Do not communicate correct and incorrect answers only through color.

Use text, icons, labels or other accessible indicators in addition to any color distinction.

---

## 8. Multilingual learning

Learning checks should appear in the current page language.

Supported languages:

RU / NL / EN / ES

The four language versions should test the same core learning objectives.

Translate questions naturally rather than mechanically word-for-word.

Preserve scientific meaning across translations.

If a technical term is commonly used internationally in English, it may be shown alongside the natural local-language term where educationally useful.

---

## 9. Applied learning

Where appropriate, include questions that require the learner to apply a concept to a new example rather than simply repeat the article.

For example:

- identify which psychological mechanism best explains a scenario;
- distinguish correlation from causation;
- interpret a simple statistical result;
- identify a misconception;
- predict what would happen if one part of a biological mechanism changed.

Keep scenarios educational and proportionate to the level of the material.

---

## 10. Avoid unnecessary gamification

Do not automatically add:

- leaderboards;
- points systems;
- streaks;
- competitive ranking;
- badges;
- social comparison;
- engagement loops.

These features require explicit owner approval.

The goal is learning quality, not maximizing time on site.

---

## 11. Quiz testing

When implementing a learning check, test at least:

- correct answers;
- incorrect answers;
- unanswered questions;
- partially completed quizzes;
- reset/retry behavior if present;
- educational feedback;
- keyboard interaction;
- mobile interaction;
- accessible state communication;
- all four language versions where applicable.

Verify the answer key against the educational content before publication.

---

## 12. Definition of a good learning check

A good Sensus Vitae learning check should leave the reader understanding the subject better than before they answered it.

If a quiz only produces a score and does not improve understanding, redesign it.
